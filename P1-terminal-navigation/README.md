## Aim
To create a project folder and practice navigating directories using macOS Terminal.

## Procedure
1. Open Terminal.
2. Create a folder using `mkdir`.
3. Enter the folder using `cd`.
4. Display the current path using `pwd`.
5. List files using `ls` and move to the parent directory using `cd ..`.

## Commands
```bash
mkdir web-lab
cd web-lab
mkdir p1-navigation
cd p1-navigation
pwd
ls -la
cd ..
```

## Output
Terminal displays the current directory path and the contents of the folder.

## Result
Successfully created folders and navigated directories using Terminal commands.
