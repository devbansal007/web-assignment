# P1 — Project folder and terminal navigation

## Aim
Create a project folder and navigate through it using Terminal.

## Commands (macOS)
```bash
mkdir web-lab
cd web-lab
mkdir p1-navigation
cd p1-navigation
pwd
ls -la
cd ..
```

- `mkdir`: creates a folder.
- `cd`: changes the current directory.
- `pwd`: displays the current folder path.
- `ls -la`: lists files, including hidden files.
- `cd ..`: moves one level up.
