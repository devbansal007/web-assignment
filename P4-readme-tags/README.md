# P4 — GitHub README and Version Tags

**Name:** Devansh Bansal | **Course:** B.Tech CSE (AI & ML)

## Aim
To document a project using README.md and mark a release with a Git version tag.

## Procedure
1. Write a README describing the project, features, setup, usage, and author.
2. Commit and push the README.
3. Create and push an annotated version tag.
4. Publish a GitHub release using the tag.

## Commands
```bash
git add README.md
git commit -m "Add project documentation"
git push origin main
git tag -a v1.0.0 -m "First portfolio release"
git push origin v1.0.0
git tag
````

## Output
README.md is visible on the repository page and the v1.0.0 tag appears in GitHub.

## Result
Project documentation and a version tag were added successfully.
