# P2 — Portfolio Repository with an Initial Commit

**Name:** Devansh Bansal | **Course:** B.Tech CSE (AI & ML)

## Aim
To initialize a Git repository for a portfolio and push its first commit to GitHub.

## Procedure
1. Open the portfolio folder in Terminal.
2. Initialize Git and stage the files.
3. Create the initial commit.
4. Connect the GitHub repository and push the main branch.

## Commands
```bash
git init
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin https://github.com/devbansal007/web-assignment.git
git push -u origin main
```

## Output
The portfolio files appear in the GitHub repository after pushing.

## Result
A Git repository was initialized and its initial commit was uploaded to GitHub.

> If the GitHub repository already contains commits, clone it first or pull before pushing.
